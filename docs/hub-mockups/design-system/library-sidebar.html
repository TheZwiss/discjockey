Library sidebar (stage 5)

State 1280 × 800 · shoot one state with #sidebar, #playlist or #folder
a · The Library group: All tracks, the playlists, the folders, Not in a playlist

The group stays rows of the sidebar, like Dashboard or Sync above it: the same 30 px rows, the same 14 px glyph slot, the same pill when selected, one right edge for every count. Nothing new floats, nothing reserves space. The four parts are told apart by a 10 px pause between them and by their icon, not by more captions: playlists carry their service's original logo in its own colours (Spotify, Qobuz, SoundCloud, YouTube Music), folders a folder outline, the two views (All tracks, Not in a playlist) no icon and start at the row's inset as today, because they come from nowhere (and "Not in a playlist" needs the width). Subfolders: a folder with subfolders that hold music has a chevron in its own column right before the count; it turns down when open, and choosing the folder opens it too, so clicking a folder is enough to find what is inside. A subfolder has no icon of its own: its name starts under its parent's name, 12 px further a level deeper, so a name like "Techno 2019" still fits the 168 px.

SignalMeans exactly this, nowhere else
Row at half strengthA switched-off playlist (Playlists page): its files stay, nothing new downloads. Its count is its last read. The sidebar's only dim.
Yellow ! in the icon slotThe folder's drive isn't connected, or the folder isn't found: the same mark Settings → Watched folders and the Library's AwayTag use. Name and count stay at full strength, because the files are still in the library. Tooltip: "Offline: connect the drive" / "Folder not found".
The service's logoWhich service the playlist is read from: the original logo in its own colours (Spotify, Qobuz, SoundCloud, YouTube Music), unchanged. The only colour in the sidebar besides the yellow !.
Folder outlineA folder on disk: a watched folder of your own music, or a folder in Library/ that no playlist uses. Its subfolders have no icon; they indent under its name.
NumberPlaylist: its songs (also those without a file yet). Folder: the files in it and below. All tracks, Not in a playlist: files.
The sidebar at 2× (to check alignment)
b · A playlist: its songs wherever their files are, then what else is in its folder

The playlist's songs in the playlist's order (the # column, the view's own default sort). A file outside the playlist's folder says where it is after the title, quieter than the title and giving way before it: in Techno 2019 (a file of your own), in Powertrance (another playlist's folder). An offline file keeps the Library's AwayTag in the quality column and is dimmed (it can't play). A song with no file is dimmed with its words in the same column: Waiting (downloads at the next sync; no colour, nothing is wrong) or the red NOT FOUND To-do already shows. Under them, Also in this folder: files in Hard_Bounce that aren't in this playlist, as a section of the same table; a song that left every playlist is dimmed as everywhere, one in another playlist is not.

c · A folder: the files physically in it and its subfolders

A folder's view lists what is on disk there. Subfolder is a column (the first that appears as the table gets wider; "–" is the folder itself), and the default sort, so the files read in the order of the tree. Playlist is the name of the first playlist that holds the song, in your playlist order, as a neutral badge; "+1" when more hold it (the tooltip names them all). A file of your own in no playlist has no badge and is never dimmed. A file whose sound isn't checked yet keeps the neutral "Not checked" badge. Length is the first optional column to go: hidden at 1280, so titles and subfolder paths fit.
