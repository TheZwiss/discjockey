Before: what's wrong

The filter chips wrap onto two lines at 1100 and stop short of the rows' edge. The groups are uppercase captions with rows on the bare background, so 299 to-dos are one long scroll where "Not found" (56) pushes everything else off screen and the page header and filter scroll away. The panel uses a 190 px cover and hairline cards; each kind of to-do hides its main action somewhere else (Swap inside an orange box, "Done, checked" inside a card, "Good enough, hide" as a ghost button at the very end), and the facts are loose sentences.

A: one anchored list, the groups are sections inside it (recommended)

Anchored: the header and the filter stay put; the one list fills the rest of the height and scrolls inside, like Dashboard's folders. Each group is a section head inside the list (name · count · one-line hint) that sticks to the list's top while its rows pass, the way Mail groups by date. The filter is a Segmented on one line: All · rekordbox · Upgrades · Not found · Weak, and the rest (Good lossy, Fake lossless, Other) in More ▾. Show hidden moves into the list's head. New in the system: sections inside a Surface list (block + gallery + doc).

B: one Surface per group in a scrolling column, as Sync's plan does

Every group is its own Surface with a sticky head; the whole column scrolls, so the header and the filter scroll away. No new block is needed, but it is exactly what the anchored-list rule forbids: at 299 to-dos, "Not found" (56) pushes Weak, Good lossy and Fake off screen until you scroll past it.

Panel (both options): head · details that scroll · the to-do's main action in the foot

Head: a compact track card (56 px cover, name, artist · length · folder, quality badge and its words) with Hide as a link, where every kind finds it. Body: what this to-do needs, then the current file with its cutoff as a number over the spectrum and player, then "Get a lossless file" (free download, buy links, drop zone). Foot: the one filled button is the to-do's own action: Swap (or Add as new file when it doesn't match), Done, checked in rekordbox, Find a version for not found, Show in Finder for other. A weak or lossy file has no action in the app (you buy it, then drop it), so its foot stays empty; the buy links and the drop zone are its actions.
