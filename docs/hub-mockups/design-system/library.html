Before: what's wrong

The page still sits on the old SplitView with the old ChipGroup: at 1100 the chips wrap onto two lines, and the sort headers stretch across their columns (the checker fails 27 of 36 shots, all for that). The table lies loose on the black, not in a container, and the "Double-click plays · ⌘F …" line hangs at the window's bottom, far from the rows it explains. "60 % lossless" is only text. In All tracks, "NOT IN A PLAYLIST" takes the quality column's place, so a column means two things, and there's no folder column, though All tracks spans every folder. At 2560 the empty panel is a dark column saying "Pick a track". In the panel, a 200 px cover takes the top quarter, the facts float on the background, the spectrum shows twice when an upgrade is ready (big, and again as "Now"), the file path breaks mid-word, and Swap, the one thing to do, sits below the window's edge at 1280. Nothing in the panel looks like To-do's panel for the same track.

After: one anchored table, a panel that matches To-do

Main: header (title · track count, search). Then the quality filter as one Segmented with dots and counts (Fake only when there is one), and the tracks as one Surface table that fills the rest of the height and scrolls inside, with its column head stuck at the top. Sort headers keep their natural width. The UPGRADE marker gets its own fixed slot, the same as To-do's. More space shows more: extra columns appear as the table gets wider: Source, then Added (in All tracks: Folder, then Source, then Added). An unlisted track keeps its real quality badge; its row dims, and in All tracks its folder reads "Not in a playlist". Play: hovering a row turns its cover into ▶, the playing row shows ❚❚, and double-click and Enter still work. The keys move behind the ⓘ in the table's head instead of a loose line.
Panel, nothing picked: the folder at a glance instead of an empty column. The lossless share as a StatCard with the quality bar (it was only text in the header), then two rows that take you somewhere: Upgrade ready (filters to it) and Not lossless yet (opens To-do). A track picked: the same cards as To-do, in the same order: the compact track card, the upgrade box (when there is one, which also replaces the separate spectrum), or else the cutoff as a number over the spectrum, then Current file with the player, Format, Source, Added and File (folder · name, cut with "…"), with Show in Finder as the card's link. Foot: Swap the files (filled) when an upgrade matches; Open in to-do (outline) for any other track on the to-do list. A lossless track has no foot.
