Connect Spotify

Discjockey only reads your playlists. It needs a free "app" in your Spotify account, one time only (about 2 minutes).
  1. Open the Spotify developer dashboard Open ↗
  2. Click Create app. Name: anything, e.g. Discjockey
  3. Redirect URI: http://127.0.0.1:8888/callbackCopy
  4. Tick Web API, accept, Save
  5. In the app's settings, copy the Client ID and paste it here:
4f1c…e9a2 ✓ looks right
Next, your browser opens to log in to Spotify. Afterwards it comes back here by itself.
